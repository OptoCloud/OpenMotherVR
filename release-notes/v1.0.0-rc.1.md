OpenMotherVR is a rebuild of MotherVR 0.8.1, the VR mod for Alien: Isolation. It runs on Windows 10 and 11 and current VR runtimes. This is a release candidate for 1.0.0, which covers what the original mod does, plus fixes for its known problems. It does not add new features yet.

## Install

1. Download `OpenMotherVR-1.0.0-rc.1.zip` below.
2. Copy `d3d11.dll` from the zip into the game folder, next to `AI.exe`. In Steam: right-click Alien: Isolation, then Manage, then Browse local files.
3. Start SteamVR (or your OpenXR runtime), then start the game.

On first start the mod creates its options menu (`DATA\MOTHER.PAK`) from your own copy of the game's `UI.PAK`. It also writes `openvr_api.dll`, `mothervr.json` and a `mothervr_input` folder. No game files ship with the mod.

`README.txt` in the zip covers controls, settings and uninstalling. To see which release you have installed, right-click `d3d11.dll`, then Properties > Details.

## Requirements

- Alien: Isolation on Steam. The mod is tested on the Steam build of `AI.exe` from February 2015. The December 2020 build (Epic, GOG and some Steam installs) is recognised but untested, and some features may stay off on it.
- SteamVR, or any OpenXR runtime (Meta Quest Link, Pico, Windows Mixed Reality, SteamVR's OpenXR).
- Nothing else: no Visual C++ runtime, no registry changes, no copy of the original MotherVR.

## What works

- Head tracking and full stereo 3D in gameplay. Menus, videos and loading screens show on a virtual screen in front of you.
- Two runtimes: OpenVR (SteamVR, the default) and OpenXR. Choose one in Options > MotherVR, or force one with the launch options `-vrforceopenvr`, `-vrforceopenxr` or `-vrforcenone`.
- VR controllers through SteamVR Input, with default bindings for Index, Touch/Quest, WMR and Vive wands. You can rebind them in SteamVR. Xbox controllers also work.
- Snap turning, recentering (Ctrl+Alt, or LB+RB), and a fade to black when your head goes into a wall.
- The MotherVR options page in the game's own menu, and the original's `mvr_*` console commands.
- Game audio plays through the headset on Meta runtimes (OpenXR).
- Discord shows that you are playing in VR, with the area and what you are doing. Turn it off with `"DiscordRichPresence": false` in `mothervr.json`.

## Fixes to the original MotherVR

- Loads on Windows 11. The original was a `dxgi.dll` proxy, which Windows 11 no longer loads from the game folder. This one is a `d3d11.dll` proxy.
- The gamepad works while the mod is loaded, and controller prompts show.
- Each eye renders at full resolution, not half.
- Lighting on floors and walls is the same in both eyes. The game's screen-position dither made the right eye look different, which looked like reflections sliding against your head.
- The desktop mirror fills the window, not just one corner.
- Fixed a render target leak every frame and out-of-range reads in the input hooks.
- Controls work on every common controller under SteamVR, not only the Vive wand.
- Objects at the edge of your view no longer pop in. The game culled them using a flat-screen field of view.
- The wall fade waits 600 ms before going black, so walking through doorways does not flash.
- FXAA and SMAA work in VR. SMAA T2x runs as T1x because there is no per-eye history.
- Planar reflections are rendered separately for each eye.

## Known issues

- No tracked hands. The controllers act as a gamepad. Hand tracking is planned for 2.0.
- "Pixel Scale" in the MotherVR menu multiplies the resolution your runtime already asks for. Leave it at 1.0 and use SteamVR's resolution slider instead.

## Reporting problems

Open an issue and attach `mothervr.log` from the game folder. If the game crashes, also include the "AI.exe" error from Windows Event Viewer (Windows Logs > Application).

## Verifying the download

`SHA256SUMS.txt` has the SHA-256 of the zip and of `d3d11.dll`. Every release also has a GitHub build provenance attestation. To check one with the GitHub CLI:

```
gh attestation verify OpenMotherVR-1.0.0-rc.1.zip --repo OptoCloud/OpenMotherVR
```
