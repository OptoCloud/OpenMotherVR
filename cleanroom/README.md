# OpenMotherVR

An open-source VR mod for Alien: Isolation, written from scratch in a clean
room. It aims to do what MotherVR 0.8.1 did (play the whole game in a modern
PC VR headset through the game's own hidden Oculus DK2 rendering path) on
Windows 11 and current VR runtimes, and to fix that mod's known problems.

Status: specification in progress (`spec/`). See `CLEANROOM.md` for how the
project is built and what may and may not go into it.
